# SEO operations

Global metadata, LocalBusiness structured data, robots rules and the XML sitemap are generated by the application. Published projects and visible services enter the sitemap automatically.

For each service or project:

- write a unique title of roughly 50–60 characters;
- write a useful description of roughly 140–160 characters;
- use the real city only when confirmed;
- avoid duplicate thin pages;
- select a representative real cover image;
- keep slugs short, lowercase and stable.

After launch, verify the domain in Google Search Console, submit `/sitemap.xml`, and inspect indexing and Core Web Vitals. Configure the Google Business Profile separately with the verified phone, website and service areas.
